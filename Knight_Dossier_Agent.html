? Aide — Knight Dossier Agent

C'est quoi ce fichier ?
Knight Dossier Agent est une application web offline — un seul fichier HTML qui fonctionne directement dans ton navigateur, sans installation ni connexion internet.

Les données sont sauvegardées automatiquement dans le navigateur (base locale du navigateur) et exportables en JSON pour les sauvegarder ou les partager.
Premier lancement
1
Double-clique sur Knight_Dossier_Agent.html — s'ouvre dans Chrome ou Edge (recommandés).
2
L'onglet ◈ Dossier s'affiche en premier, vide au démarrage.
3
Va dans Identité pour renseigner nom, section, PG/PX, Lumière & Ombre.
4
Remplis Aspects, Combat & Arsenal et Méta-Armure.
5
La sauvegarde est automatique — ✓ SAUVEGARDÉ confirme chaque enregistrement.

? AideCette fenêtre d'aide
◈ Dossier
Vue synthèse : Portrait + Blason en haut, Aspects, puis 2 colonnes (Illustration | Valeurs + Méta-Armure + Modules), puis Arsenal pleine largeur. Se reconstruit à chaque visite.
Identité
Nom, vrai nom, section, origine, vœu, PG/PX, Méta-Armure (affichage), Lumière & Ombre, Héroïsme, Biographie, zones d'images (Portrait, Illustration, Blason) + galerie d'illustrations multiples.
Aspects
Les 5 aspects (Corps, Puissance, Esprit, Grâce, Subterfuge) — MAXIMUM de chaque aspect, puis sous-aspects avec Val + OD. Les capacités de rang sont affichées en référence.
Combat & Arsenal
Arsenal (arme, dégâts, violence, portée, munition, effets), Grenades + NODS, Styles de combat actifs, référence portées.
Méta-Armure
PA / PE / CdF / IA (saisie ici, affichée en lecture dans Identité), Slots avec modif + total calculé, 2 Capacités, Notes libres, 5 Modules, Fonctions Communes.
📋 Feuille de Perso
Vue étendue complète de la fiche. Se reconstruit à chaque clic depuis les données en cours — toujours synchronisée.

Charger une image locale
1
Clique sur la zone d'image ou glisse-dépose un fichier image directement.
2
L'image est convertie en base64 et incluse dans le JSON exporté.
⚠ Les images base64 alourdissent le JSON (~1 Mo par image). Pour rester léger, utilise des liens Google Drive.
Charger une image via lien Drive
1
Upload l'image sur Google Drive.
2
Clic droit → Partager → "Tout le monde avec le lien peut voir" → Copier le lien.
3
Colle ce lien dans le champ Lien Google Drive… sous la zone image. L'app extrait l'ID automatiquement — le champ devient vert si valide.
4
Seul l'ID Drive est stocké dans le JSON — fichier léger, image chargée depuis Drive à l'ouverture.
⚠ Si l'image ne s'affiche pas : vérifie que le partage est "Tout le monde avec le lien" et non limité à ton compte Google.
Illustrations multiples
Dans l'onglet Identité, section "Illustrations" en bas à droite : clique sur + Ajouter une illustration. Chaque illustration a une légende libre (ex: "En armure", "Civil", "En action"). Accepte fichier local ou lien Drive.
Plusieurs agents
1
Le bouton 🗂 Base d'agents ouvre une fenêtre où chaque agent est un dossier. Elle s'ouvre aussi toute seule au démarrage dès qu'il y a plusieurs agents.
2
Clique sur un dossier pour ouvrir l'agent. Les petits boutons du dossier permettent d'exporter (⬇) ou de supprimer (🗑).
3
Le dossier en pointillés ＋ Nouvel agent crée une fiche vide et ouvre l'onglet Identité.
Importer des agents
1
⬆ Importer des JSON : sélectionne un ou plusieurs fichiers .json d'un coup.
2
📁 Importer un dossier (ordinateur uniquement) : tous les .json du dossier sont chargés.
3
⬇ Tout exporter crée un seul fichier knight_agents.json avec tous les agents ; il se réimporte de la même façon.
Si un agent du même nom existe déjà, l'app demande : OK pour remplacer la version actuelle, Annuler pour garder les deux.
Où sont les données ?
Les agents sont enregistrés automatiquement dans la base locale du navigateur (IndexedDB), sans limite pratique de taille.
⚠ Cette base est liée au navigateur, à l'appareil et à l'adresse du site. Vider les données de navigation l'efface. Fais un ⬇ Tout exporter de temps en temps.
Dossier de sauvegarde (un dossier par agent)
Structure créée par l'app : 
Knight/
├─ index.json                  liste des agents + dossiers
├─ Agent 01/
│  ├─ agent.json               la fiche
│  └─ images/                  portrait, illustrations, blason
└─ Agent 02/
   └─ agent.json
1
Sur Chrome ou Edge (ordinateur), dans la Base d'agents (section « Dossier de sauvegarde ») : 📂 Choisir / créer le dossier, puis sélectionne un dossier, par exemple Knight dans ton dossier Google Drive.
2
S'il est vide, l'app crée index.json et le dossier de l'agent ouvert (le nom du chevalier doit être renseigné).
3
💾 Sauvegarder (en haut) met à jour agent.json, les images et index.json. 💾 Tout enregistrer le fait pour tous les agents.
4
Sur un autre ordinateur, choisis le même dossier (synchronisé par l'appli Google Drive), puis 📥 Charger depuis le dossier.
Les dossiers sont anonymes par défaut (Agent 01, Agent 02…) : c'est index.json qui indique à quel personnage correspond chaque dossier. Le réglage « Nom des dossiers » permet d'utiliser le nom du chevalier. Les images chargées depuis ton ordinateur sont enregistrées comme fichiers dans images/ (le JSON ne contient que leur chemin). Les images liées via Google Drive restent des liens. Le dossier d'un agent garde son nom initial même si tu renommes le chevalier.
Firefox, Safari, téléphone : ces navigateurs ne peuvent pas écrire dans un dossier. Utilise 🗜 Structure en ZIP et extrais-le dans ton dossier. Pour recharger, utilise 📁 Importer un dossier (ordinateur) : les images sont retrouvées grâce aux chemins, index.json est ignoré.
Version hors ligne
1
Dans la Base d'agents, clique 💾 Version hors ligne : le fichier HTML se télécharge.
2
Ouvre-le par double-clic : il fonctionne sans connexion.
⚠ La copie locale a sa propre base, séparée de la version en ligne. Pour transférer tes agents : ⬇ Tout exporter d'un côté, ⬆ Importer de l'autre.
Sauvegarde automatique
Toute modification est enregistrée automatiquement après 1,2 seconde, et aussi quand tu quittes la page. Indicateur en haut :

● NON SAUVEGARDÉ — modification en cours
✓ SAUVEGARDÉ — agent enregistré
⚠ ÉCHEC SAUVEGARDE — l'écriture a échoué : exporte le JSON par précaution
● EN VEILLE — aucune modification récente
