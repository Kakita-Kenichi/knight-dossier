⊞ Généralités
Ce fichier HTML fonctionne 100% hors-ligne — aucune installation, aucun serveur. Il suffit de double-cliquer dessus pour l'ouvrir dans ton navigateur. Toutes les données sont stockées localement dans ton navigateur (localStorage).
1
Fichier unique
Tout est dans un seul fichier Knight_Dossier_Agent.html. Tu peux le copier, le renommer, l'archiver. Chaque copie est indépendante avec ses propres données.
2
Navigation par onglets
◈ Dossier Vue synthèse du personnage
Identité Infos, images, Lumière/Ombre
Aspects Les 5 aspects et sous-aspects
Combat & Arsenal Armes, styles, grenades, NODS
Méta-Armure Armure, slots, capacités, modules
📋 Feuille de Perso Fiche complète à imprimer
3
Saisie des données
Tous les champs sont éditables directement. Les données sont sauvegardées automatiquement 1,2 seconde après la dernière frappe. L'indicateur en haut à droite confirme : ✓ SAUVEGARDÉ
💾 Sauvegarde locale
Les données sont sauvegardées automatiquement dans le localStorage de ton navigateur — elles persistent entre les sessions tant que tu utilises le même navigateur sur le même ordinateur.
⬇
Exporter en JSON
Bouton ⬇ JSON dans la barre du haut. Télécharge un fichier .json contenant toutes les données du personnage (stats, arsenal, modules, liens images Drive). Recommandé comme sauvegarde de secours avant chaque session.
⬆
Importer un JSON
Bouton ⬆ Importer. Charge un fichier .json précédemment exporté. Remplace toutes les données actuelles. Utile pour changer d'ordinateur ou récupérer une sauvegarde.
!
Réinitialiser
Bouton ✕ Reset — efface toutes les données définitivement. Une confirmation est demandée. Pense à exporter ton JSON avant.
⚠ Le localStorage est lié au navigateur et au profil. Si tu changes de navigateur, d'ordinateur ou vides le cache, les données disparaissent. Exporte régulièrement en JSON ou utilise la synchronisation Drive.
☁ Google Drive — Synchronisation JSON
Le bouton ☁ Drive JSON permet de sauvegarder et charger le dossier depuis Google Drive, sans installation ni compte développeur.
1
Sauvegarder sur Drive
1. Clique ☁ Drive JSON → section Sauvegarder
2. Ajuste le nom du fichier si besoin (ex: dipa_dossier.json)
3. Clique ⬇ Télécharger — le fichier se télécharge localement
4. Va sur drive.google.com et glisse-dépose le fichier dans ton Drive
5. Clic droit sur le fichier → Partager → "Tout le monde avec le lien peut voir"
6. Copie le lien → colle-le dans le champ "Charger depuis Drive" ci-dessous
2
Charger depuis Drive
1. Ouvre le modal ☁ Drive JSON
2. Colle l'URL de partage Drive dans le champ
3. Clique ⬆ Charger
4. Le lien est mémorisé dans le navigateur pour les prochaines sessions
3
Mettre à jour le fichier Drive
Drive ne permet pas l'écriture directe sans OAuth. Le flux de mise à jour est :
1. ⬇ Télécharger le nouveau JSON
2. Sur Drive, clic droit sur l'ancien fichier → Gérer les versions → Importer une nouvelle version
→ Le lien reste le même, les données sont mises à jour.
💡 Astuce : utilise Gérer les versions pour conserver un historique des sauvegardes sans multiplier les fichiers sur Drive.
⚠ Le fichier Drive doit être partagé en "Tout le monde avec le lien peut voir". Sans ce partage, le chargement échoue avec une erreur HTML.
☁ Google Drive — Images
Les images (Portrait, Illustration, Blason) peuvent être liées depuis Drive. L'avantage : le JSON reste léger (pas de base64), et les images sont centralisées sur Drive.
1
Préparer l'image sur Drive
1. Upload ton image sur Drive (PNG, JPG, WEBP…)
2. Clic droit → Partager → "Tout le monde avec le lien peut voir"
3. Clique Copier le lien — tu obtiens quelque chose comme :
https://drive.google.com/file/d/1aBcDeFgHiJ.../view?usp=sharing
2
Coller dans l'app
Dans l'onglet Identité, sous chaque zone image, il y a un champ texte. Colle le lien Drive dedans.
→ Le champ devient vert si l'ID est reconnu
→ L'image tente de se charger avec 3 formats d'URL différents en fallback automatique
→ Un badge ☁ DRIVE confirme que l'image vient de Drive
3
Formats de lien acceptés
L'app reconnaît automatiquement ces formats :
https://drive.google.com/file/d/ID/view?usp=sharing https://drive.google.com/open?id=ID https://drive.google.com/uc?id=ID ID seul (20+ caractères alphanumériques)
4
Images locales vs Drive
Image locale (glisser-déposer / cliquer) : stockée en base64 dans le JSON → fonctionne sans connexion internet mais alourdit le fichier.
Image Drive (lien) : seul l'ID est stocké dans le JSON → fichier léger mais nécessite une connexion et que le fichier Drive reste partagé.
⚠ Si l'image ne s'affiche pas après avoir collé le lien, vérifie que le fichier Drive est bien partagé en "Tout le monde avec le lien". Certains navigateurs (Firefox) bloquent aussi les images cross-origin — Chrome est recommandé.
⊞ Guide des onglets
ID
Identité
Informations de base du chevalier, valeurs dérivées, Méta-Armure (lecture seule — saisie dans l'onglet Méta-Armure), Lumière & Ombre, Héroïsme, images (Portrait / Illustration / Blason + galerie d'illustrations multiples).
ASP
Aspects
5 aspects : Corps, Puissance, Esprit, Grâce, Subterfuge. Chaque aspect a un Maximum. Chaque sous-aspect (Endurance, Force, Déplacement…) a une Val et un OD. Les capacités de chaque rang sont affichées en dessous à titre de référence.
COM
Combat & Arsenal
Arsenal : tableau d'armes avec Dégâts, Violence, Portée, Munition, Effets. Bouton + Ajouter.
Styles de combat : clic pour activer/désactiver.
Grenades : cases à cocher pour le nombre et les types.
NODS : cases Santé / Armure / Énergie.
Portées : tableau de référence.
MÉT
Méta-Armure
Données armure : Nom, PA, PE, CdF, IA — affichées en lecture seule dans l'onglet Identité.
Slots : chaque emplacement (Bras G., Jambe G., Torse, Tête, Bras D., Jambe D.) a une valeur, un modificateur (peut être négatif) et un total calculé automatiquement.
Capacités et Modules : remplis les noms pour qu'ils apparaissent dans le Dossier.
FP
Feuille de Perso
Vue complète du personnage : Aspects, Valeurs, Méta-Armure, Slots, Combat, Arsenal, Grenades, NODS, Blason. Se met à jour automatiquement à chaque visite depuis les données saisies dans les autres onglets. Bouton 🖨 Imprimer disponible.

Le Dossier est la vue de synthèse rapide. Il se met à jour automatiquement à chaque ouverture de l'onglet.

? FAQ
?
Mon image Drive ne s'affiche pas
1. Vérifie que le fichier est partagé "Tout le monde avec le lien peut voir"
2. Essaie avec Chrome plutôt que Firefox
3. Si l'image est très grande (>10 Mo), Drive peut bloquer le chargement direct → compresse l'image
?
Mes données ont disparu
Le localStorage a probablement été vidé (nettoyage du cache, navigation privée, autre navigateur). → Importe ton dernier JSON de sauvegarde avec ⬆ Importer
→ Ou charge depuis Drive avec ☁ Drive JSON
?
La Feuille de Perso ne se met pas à jour
La mise à jour se déclenche à chaque visite de l'onglet. Si les données semblent obsolètes, clique sur un autre onglet puis reviens sur Feuille de Perso.
?
Le chargement Drive retourne une erreur HTML
Drive affiche une page d'avertissement pour les fichiers volumineux. → Essaie de réduire la taille du JSON en utilisant des liens Drive pour les images plutôt que des images en base64.
?
Méta-Armure dans Identité ne se met pas à jour
Les données Méta-Armure (PA, PE, CdF, IA, Nom armure) se saisissent dans l'onglet Méta-Armure et s'affichent en lecture seule dans Identité. La mise à jour est en temps réel pendant la saisie, et au retour sur l'onglet Identité.

? Guide — Knight Dossier Agent

C'est quoi ce fichier ?
Knight Dossier Agent est une application web offline — un seul fichier HTML qui fonctionne directement dans ton navigateur, sans installation ni connexion internet.

Les données sont sauvegardées automatiquement dans le navigateur (localStorage) et exportables en JSON pour Drive ou clé USB.
Premier lancement
1
Double-clique sur Knight_Dossier_Agent.html — s'ouvre dans Chrome ou Edge (recommandés).
2
L'onglet ◈ Dossier s'affiche en premier, vide au démarrage.
3
Va dans Identité pour renseigner nom, section, PG/PX, Lumière & Ombre.
4
Remplis Aspects, Combat & Arsenal et Méta-Armure.
5
La sauvegarde est automatique — ✓ SAUVEGARDÉ confirme chaque enregistrement.

Les 5 aspects (Corps, Puissance, Esprit, Grâce, Subterfuge) — MAXIMUM de chaque aspect, puis sous-aspects avec Val + OD. Les capacités de rang sont affichées en référence.

Méta-Armure

Charger une image locale
1
Clique sur la zone d'image ou glisse-dépose un fichier image directement.
2
L'image est convertie en base64 et incluse dans le JSON exporté.
⚠ Les images base64 alourdissent le JSON (~1 Mo par image). Pour rester léger, utilise des liens Google Drive.
Charger une image via lien Drive
1
Upload l'image sur Google Drive.
2
Clic droit → Partager → "Tout le monde avec le lien peut voir" → Copier le lien.
3
Colle ce lien dans le champ Lien Google Drive… sous la zone image. L'app extrait l'ID automatiquement — le champ devient vert si valide.
4
Seul l'ID Drive est stocké dans le JSON — fichier léger, image chargée depuis Drive à l'ouverture.
⚠ Si l'image ne s'affiche pas : vérifie que le partage est "Tout le monde avec le lien" et non limité à ton compte Google.
Illustrations multiples
Dans l'onglet Identité, section "Illustrations" en bas à droite : clique sur + Ajouter une illustration. Chaque illustration a une légende libre (ex: "En armure", "Civil", "En action"). Accepte fichier local ou lien Drive.
Sauvegarder le dossier sur Drive
1
Clique sur ☁ Drive JSON dans le header.
2
Modifie le nom du fichier si besoin, clique ⬇ Télécharger — le JSON se télécharge dans tes Téléchargements.
3
Ouvre drive.google.com → glisse le fichier JSON dans Drive ou + Nouveau → Importer un fichier.
4
Clic droit sur le fichier JSON dans Drive → Partager → "Tout le monde avec le lien peut voir" → Copier le lien.
5
Colle ce lien dans le champ Charger depuis Drive du modal et clique ⬆ Charger. Le lien est mémorisé pour les prochaines sessions.
Charger depuis Drive (sessions suivantes)
1
Clique sur ☁ Drive JSON.
2
Le lien mémorisé apparaît — clique directement sur ⬆ Charger.
⚠ Si Drive retourne une page HTML au lieu du JSON : le fichier n'est pas partagé correctement. Refais l'étape 4 ci-dessus.
Workflow recommandé
Début de session : Ouvre le HTML → ☁ Drive JSON → Charger.
Fin de session : ☁ Drive JSON → Télécharger → glisser dans Drive (remplace l'ancien fichier).

Conseil : Garde le fichier .html et le .json dans le même dossier Drive. Tu peux tout télécharger et utiliser sur n'importe quel ordinateur.
